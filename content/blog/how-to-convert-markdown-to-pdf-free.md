## What is converted

Headings, lists, links, tables, and fenced code blocks. The same Markdown parser that renders these guides is used, so raw HTML in the file is escaped rather than executed.

## How to convert Markdown to PDF

1. Open **Markdown to PDF**.
2. Upload a `.md` file.
3. Click **Convert to PDF** and check the preview. Long code lines and table cells wrap instead of running off the page.
4. Click **Save as PDF** and choose **Save as PDF** in the print dialog.

## What will look different

Wide tables are squeezed to the page width, not given a custom paper size. Fonts are the browser's, not a desktop Markdown previewer's. That is the print path, not a bug.

## Privacy

The file is parsed in your browser. It is not uploaded.
