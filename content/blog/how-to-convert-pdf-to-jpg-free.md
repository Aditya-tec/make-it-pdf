## When would you convert a PDF to JPG?

- Embedding a page from a PDF into a Word document or presentation
- Posting a document page as an image on social media
- Thumbnail generation for a document library
- Archiving old scans in a universal image format

## How to convert PDF to JPG free

1. Open the **PDF to JPG** tool.
2. Upload your PDF.
3. Choose your settings:
   - **Format**: JPG (smaller file) or PNG (lossless, with transparency).
   - **DPI**: 72 for web preview, 150 for general use, 300 for print-quality.
4. Click **Convert** and wait for pages to render.
5. For single-page PDFs, download one image directly. For multi-page PDFs, download a ZIP file containing all pages.

## Understanding DPI

DPI (dots per inch) controls the image resolution:

- **72 DPI**: Screen-quality, small files. Good for web thumbnails.
- **150 DPI**: Good quality, moderate file size. The safe default.
- **300 DPI**: Print quality, large files. Slow on mobile for large pages.

**Tip**: Avoid 300 DPI on mobile — rendering a large page at high resolution uses significant memory and may be slow or fail on older devices.

## JPG vs PNG — which to choose?

| Format | Best for | File size |
|--------|----------|-----------|
| JPG | Photos, scanned pages | Smaller |
| PNG | Text, diagrams, transparency | Larger |

For most document conversions, JPG at 90% quality is the right choice.

## Privacy: does anything leave my device?

No. This tool uses pdf.js (the same engine as Firefox's built-in PDF reader) running as WebAssembly in your browser. No file data is transmitted.
