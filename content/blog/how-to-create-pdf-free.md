## What this editor is

A small box for a letter or a note. Buttons for **bold**, **italic**, a **heading**, and a **list**. It is not Google Docs, and it is not trying to be.

Paste comes in as plain text, so a copied webpage cannot run code in the editor. Add formatting with the buttons.

## How to create a PDF

1. Open **Create PDF**.
2. Type. Use the buttons for formatting.
3. Click **Create PDF**.
4. Click **Save as PDF** and choose **Save as PDF** in the print dialog.

The preview uses the same sanitizing print path as HTML to PDF.

## Privacy

The document never leaves the tab. Close it and the draft is gone.
