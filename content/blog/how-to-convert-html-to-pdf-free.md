## What is removed before you see a preview

This tool accepts whatever HTML you give it, so the preview is locked down:

- Script tags, event handlers (`onerror` and the rest), and `javascript:` links are stripped.
- Remote images are removed so the preview does not contact another site.
- The preview frame cannot run scripts.

If nothing safe is left, the tool says so instead of printing a blank page.

## How to convert HTML to PDF

1. Open **HTML to PDF**.
2. Paste HTML into the box, or upload an `.html` / `.htm` file. An uploaded file is used instead of the box.
3. Click **Convert to PDF** and read the preview.
4. Click **Save as PDF** and choose **Save as PDF** in the print dialog.

## Privacy

Sanitizing and printing happen on your device. The HTML is not uploaded.
