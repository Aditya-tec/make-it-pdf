## What it does

Each run stamps a unique ID into the PDF's metadata and as near-invisible text on every page. Send each recipient their own copy and note which ID went to whom.

## What it is not

This is a **deterrent, not forensic tracking**. Printing to a new PDF, flattening, screenshots, or stripping metadata can remove the ID. Nothing is stored anywhere; the ID is shown once, so write it down.

## How to use it

1. Open **Fingerprint PDF** and add your PDF.
2. Optionally type the recipient's name.
3. Download the copy and record the ID.

## Privacy

Everything happens on your device.
